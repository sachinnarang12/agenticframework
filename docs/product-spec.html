What is AgentFlow?

AgentFlow is an open-source multi-agent AI framework that coordinates multiple Claude AI models — each with a specialist role — to automate complex financial workflows.

🧠

Multiple Specialist Agents

Each agent has a defined role — Researcher, Bull Analyst, Bear Analyst, Risk Manager, Report Writer. They work together like a real investment team.

⚔️

Built-in Challenge Mechanism

A dedicated Bear Analyst always stress-tests the bull case. No groupthink. Every investment thesis is challenged before a recommendation is made.

📋

Full Audit Trail

Every agent's reasoning is logged and visible. Compliance teams can see exactly how a recommendation was reached — step by step.

⚡

Real-time Streaming

Watch each agent think and respond live — token by token — through the web UI. No waiting for a black-box answer.

🔧

Fully Customisable

Swap models, change system prompts, add tools (web search, databases, Bloomberg). Build on top of the framework for your specific workflow.

☁️

Deploy Anywhere

Run locally, on GitHub Codespaces, or deploy to Anthropic Agent Core for fully managed hosted agents with per-session containers.

Finance Use Cases

Five high-value workflows ready to deploy today.

📊

1. Earnings Call Analysis

Paste any earnings transcript. Five agents extract facts, build bull and bear cases, stress-test risks, and produce a downloadable investment memo — in minutes.

Researcher → Bull Analyst → Bear Analyst → Risk Manager → Investment Memo

2. Portfolio Position Debate

Two agents take opposing sides on whether to hold, increase, or exit a position. A Risk Manager synthesises a recommendation with position sizing guidance.

Bull Agent ↔ Bear Agent (N rounds) → Risk Manager → Final Recommendation

3. Compliance & Regulatory Review

Draft agent writes client communications or trade rationale. Compliance agent checks against SEC/FCA rules. Legal agent flags liability language. Final agent produces approved version.

Draft Agent → Compliance Agent → Legal Agent → Approved Output
📰

4. Market Intelligence Report

Three specialist researchers cover macro, sector, and company news simultaneously. Analyst extracts cross-cutting themes. Writer produces a morning briefing report.

Macro + Sector + Company Researchers (parallel) → Analyst → Morning Briefing

5. Client Report Generation

Data agent pulls portfolio performance. Narrative agent explains what happened and why. Tone agent adjusts language for retail vs institutional. Final agent formats the report.

Data Agent → Narrative Agent → Tone Agent → Client Report (PDF-ready)

System Architecture

Two core abstractions — Agent and Orchestrator — power all pipelines.

🤖

Agent

Each Agent wraps a Claude model with a named role, a system prompt defining its expertise, and a conversation history. Agents are stateful — they remember prior turns within a session.

agent = Agent(
  name="BullAnalyst",
  system_prompt="Build the buy case...",
  model="claude-opus-4-6"
)
response = agent.chat("Analyse Apple Q4")
🎯

Orchestrator

The Orchestrator registers agents and routes messages between them. It implements four coordination patterns: direct routing, sequential pipeline, feedback loop, and broadcast.

orch = Orchestrator()
orch.register(researcher)
orch.register(analyst)
orch.pipeline(steps, task)

Interaction Patterns

PatternHow it worksBest for
Pipeline Output of Agent A becomes input to Agent B, then C... Earnings analysis, code review, report generation
Feedback Loop Agent A produces → Agent B critiques → A revises → repeat N times Investment debate, document drafting, compliance review
Broadcast Same message sent to all agents simultaneously, responses collected Multi-angle research, risk committee views
Direct Route Send one message to one specific agent Ad-hoc queries, single-step analysis

Getting Started

Running in 5 minutes on any machine or cloud IDE.

1️⃣ Clone & Install

git clone https://github.com/
  sachinnarang12/agenticframework
cd agenticframework
pip install -r requirements.txt

2️⃣ Set API Key

# Get key from console.anthropic.com
# Linux / Mac:
export ANTHROPIC_API_KEY=sk-ant-...

# Windows CMD:
set ANTHROPIC_API_KEY=sk-ant-...

3️⃣ Launch the UI

streamlit run ui/app.py

# Or run CLI examples:
python examples/04_earnings_analysis.py

☁️ Deploy on Anthropic Agent Core

For production deployments with fully hosted agents, Anthropic manages the infrastructure.

# Step 1 — one-time setup (creates agents on Agent Core)
python managed_agents/setup.py

# Step 2 — add IDs to .env, then run sessions
python managed_agents/run_session.py
